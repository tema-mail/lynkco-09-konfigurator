# Конфигуратор Lynk & Co 09

Только конфигуратор: без шапки, логотипа, подвала и цен. Его собирают в сборку и встраивают в страницу модели на сайте.

Посмотреть: https://tema-mail.github.io/lynkco-09-konfigurator/ (закрыт от индексации).
Локально: `python3 -m http.server 8940`, затем http://127.0.0.1:8940/

## Что выбирает человек
Версия (Max); цвет кузова, диски, цвет салона.
Варианты и их сочетания взяты из официального конфигуратора Lynk & Co (lynkco.com.cn): чего производитель не собирает, выбрать нельзя.

## Картинки
Официальные рендеры Lynk & Co: один вид кузова без фона на каждую сборку (версия, цвет, диски, крыша) и фото салона на каждую отделку.
Других ракурсов у производителя картинками нет – на его сайте их показывает трёхмерная модель.
3 сборок кузова, 1 вариантов салона, всё в WebP.

## Встраивание в сайт
Скопировать блок `<div class="z9" data-z9>…</div>` из `index.html`, подключить `css/konfigurator.css`,
`js/zeekr-data.js`, `js/konfigurator.js`, положить рядом папку `img/`. Движок общий для всех моделей Zeekr,
модель задаёт только `js/zeekr-data.js` и картинки. Цвета – токены `--z9-*` в начале CSS (светлая и тёмная тема).

Заявка «Отправить сборку менеджеру»: у формы атрибут `data-endpoint` – адрес приёма заявок сайта,
туда уходит POST JSON `{name, phone, text, url, lines, source, page}`. Пока он пустой, заявка уходит событием:
```js
document.querySelector('[data-z9]').addEventListener('zeekr:lead', e => send(e.detail));
// текущая сборка в любой момент: window.ZeekrCfg.get()  → {text, lines, config, url}
// каждое изменение: событие 'zeekr:change'
```
Ссылку на политику конфиденциальности вписать в `a[data-policy]` формы. Сборка хранится в адресе (`#v=55&o=…`).

## Как обновить данные
1. `python3 tools/lynkco_snyat.py <vcId серии> .` – пишет `raw/lynk-raw.json`. Браузер не нужен, у Lynk & Co открытый API;
   с сервера в Нидерландах сайт не открывается, запрос идёт напрямую. vcId серии – из списка серий (см. начало lynkco_snyat.py).
2. `tools/lynkco-model.sh 09 "Lynk & Co 09" "09"` – картинки, данные, проверки и выкладка (NOPUSH=1 – без выкладки).
   Новое китайское название сборка не пропустит: добавить перевод в словарь RU в tools/lynkco.py.
3. Проверка выложенной страницы в браузере на сервере: `python3 tools/proverka_vps.py https://tema-mail.github.io/lynkco-09-konfigurator/`
Движок и стили общие с конфигураторами Zeekr, мастер-копия – репозиторий tema-mail/zeekr-9x-konfigurator.
